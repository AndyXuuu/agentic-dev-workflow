# oMo Scaffold

This module is the fixed entrypoint for adding new oMo/OpenCode extension pieces.

Use it when you need to add or evolve:

- plugins
- agents
- skills
- commands

The purpose is simple:

> avoid searching the whole repo every time you want to add one of these.

## Files

- `PLUGIN.md`
- `AGENT.md`
- `SKILL.md`
- `COMMAND.md`
- `CHECKLIST.md`

## Usage

Start from the matching file for the thing you want to add.

If the addition spans multiple areas, use `CHECKLIST.md` first.
