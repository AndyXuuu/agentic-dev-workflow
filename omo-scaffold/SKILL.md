# Adding a Skill

## When this applies

Use this when the feature should be exposed as a reusable skill-like workflow rather than only as a plugin or one-off prompt.

## What a skill should provide

- a clear trigger domain
- a repeatable execution pattern
- narrow, reusable expertise
- optional MCP/tool expectations

## Questions to answer first

- Is this really a reusable skill, or only a project-specific prompt?
- Does it encapsulate a repeatable workflow?
- Would multiple future tasks benefit from the same wrapper?

## Good skill candidates

- browser verification
- UI polish review
- repo archaeology
- deployment sanity checks

## Do not

- turn every prompt into a skill
- create skills with blurry scope
- hide critical environment assumptions
