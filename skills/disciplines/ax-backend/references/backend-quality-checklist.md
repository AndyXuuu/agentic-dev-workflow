# 后端质量检查表

## 契约与边界

- 已从 canonical 源契约开始修改，生成物没有手工编辑。
- Handler/controller 只处理协议、身份、输入与响应映射。
- 业务规则、权限、计费、格式化和错误映射位于既有 Owner。
- 跨模块/服务通过正式接口，不越过边界直读他方数据。
- 第三方 SDK 被 adapter/client 隔离，领域层不依赖供应商类型。

## 数据与一致性

- 每份数据有唯一写 Owner，事务覆盖真实一致性边界。
- 重复写、并发、锁、隔离、幂等键和唯一约束行为明确。
- 部分失败有原子回滚、补偿、重试或人工恢复路径。
- Migration 可排序、可验证、尽量可重入；大表锁和回填风险已评估。
- 发布顺序兼容旧/新版本并存；不可逆变化有缓解与恢复方案。

## 外部调用与异步处理

- 外部调用有 timeout；retry 有界、退避且只用于安全操作。
- Rate limit、circuit breaker、降级和依赖故障反馈符合项目策略。
- Producer/consumer 定义至少一次/至多一次语义、去重、顺序和重放。
- Worker 失败不会静默丢失；死信、告警和人工恢复入口明确。
- 定时任务和 webhook 处理重复执行、乱序、签名与过期请求。

## 安全与可观测性

- 输入在可信边界校验；认证不替代授权，租户/资源边界可验证。
- 密钥、令牌、个人数据、支付数据不硬编码、不进入日志或错误响应。
- 错误保留 cause，公共错误不泄露内部实现或敏感信息。
- 结构化日志、指标和追踪能定位关键状态转换与失败，不重复计数。
- 审计、数据保留和删除行为符合项目要求。

## 测试与交付

- Bug 回归测试修复前失败、修复后通过。
- 覆盖成功、非法输入、边界、权限、并发、重复请求和依赖失败。
- 契约测试验证兼容性，迁移测试验证前后数据和重复执行。
- 测试断言可观察行为，不复制实现逻辑或用过度 mock 隐藏集成风险。
- 已运行相关测试、模块/全量测试、静态分析、生成验证和构建。
- 已报告部署/迁移顺序、剩余风险、未验证项和回滚/恢复方式。
